# Asset manifest

| Asset | Source | Licence | Notes |
|---|---|---|---|
| League, roster, matchup, draft and player data | Sleeper public API | Public read-only API | Refreshed by GitHub Actions into `site/data/sleeper/` |
| Cinzel, Barlow Condensed, Orbitron, Bebas Neue | Fontsource npm packages | SIL Open Font License 1.1 | Embedded in `src/engine/fonts.css` for rendering only |
| Cinematic imagery, emblems, crests | Original, generated by `src/engine/*.js` | Project's own work | No third-party artwork |
| Player jerseys in the films | Original generic jersey shape drawn in `src/engine/core.js`; colours per NFL team from the `NFL` table there | Project's own work | Team colours only. No logos, wordmarks, uniform artwork or photographs |
| Music and sound effects | Original, synthesized by `src/engine/audio.py` | Project's own work | No samples |
| League history, tiers, rivalry notes in the hub | Commissioner's Playbook 2026-27 (2026-09-08) | League's own document | Used in the prototype hub only |

## Player photographs
None are used, by decision: photographs of real players are not added to the site or films from any source. Players are represented by the jersey treatment above.

## Sleeper avatars
Each owner's avatar URL is stored in `site/data/canonical.json` (`sleeper_team_avatar`, `sleeper_user_avatar`) but is not displayed anywhere. Before showing one, look at it and confirm it is the manager's own image and not a photograph of a real person or artwork of an existing character or brand; record the decision here.
