# Asset manifest

| Asset | Source | Licence | Notes |
|---|---|---|---|
| League, roster, matchup, draft and player data | Sleeper public API | Public read-only API | Refreshed by GitHub Actions into `site/data/sleeper/` |
| Cinzel, Barlow Condensed, Orbitron, Bebas Neue | Fontsource npm packages | SIL Open Font License 1.1 | Embedded in `src/engine/fonts.css` for rendering only |
| Cinematic imagery, emblems, crests | Original, generated by `src/engine/*.js` | Project's own work | No third-party artwork |
| Music and sound effects | Original, synthesized by `src/engine/audio.py` | Project's own work | No samples |
| League history, tiers, rivalry notes in the hub | Commissioner's Playbook 2026-27 (2026-09-08) | League's own document | Used in the prototype hub only |

## Player photographs
None are used. One slot per featured player is reserved so licensed photos can be added later.
To add one: put the file in `site/assets/players/<sleeper_player_id>.jpg` and add a row below. The engine does not read these yet.
